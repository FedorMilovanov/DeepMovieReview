## F. Strategic synthesis

The research points to a coherent direction:

1. **Visual system:** Obys-level editorial hierarchy + cinematic restraint + high-end creative-development craft.
2. **Signature technology:** depth-relit images, selective TSL/WebGPU effects, persistent scene architecture, meaningful shared transitions.
3. **Signature interactions:** Moral Lens, Scene Autopsy, Film Dissection, Moral Core, Moral Timeline, Decision Chamber / Knowledge Fog.
4. **Product integrity:** DOM-first readable content, progressive enhancement, WebGL2/Lite fallbacks, reduced motion.
5. **Methodology:** act/motive/knowledge/freedom/consequence + narrative stance; depiction ≠ endorsement; explanation ≠ justification.
6. **Audience:** viewer-quality score, moral-perception responses and decision distributions remain separate from editorial biblical judgment.
7. **Positioning:** not “Christian ratings already done better,” but an **interactive moral anatomy / atlas of cinema**.

## G. Ongoing audit rule

Before adopting any new visual trend, answer:

- Does it reinforce FRAME, LENS, FRACTURE, TRACE, FOG, CORE or LIGHT?
- Does it explain content or only decorate it?
- Does it survive reduced-motion and Lite modes?
- Is it still usable on touch/keyboard?
- Does it preserve readable DOM content?
- Does it materially improve comprehension, memory or atmosphere?
- What is the performance budget?

If the answer is mostly “it looks current,” it stays in R&D and does not enter the design system.
