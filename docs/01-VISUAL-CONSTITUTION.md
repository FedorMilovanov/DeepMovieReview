# DeepMovieReview — Visual Constitution

> Visual direction: **Cinematic Moral Forensics**  
> Status: v0.1 foundation  
> Audited: 2026-09-09

## 1. Core art direction

The site should not look like a Christian media portal, a streaming clone, a cyberpunk dashboard, or a generic WebGL portfolio.

The visual synthesis is:

- obsidian cinema;
- dark editorial design;
- moral forensics;
- living depth-based imagery;
- restrained optical glass;
- spatial data visualization;
- analog cinema texture;
- quiet luxury for final judgments.

Recommended composition ratio:

- **70% clean cinematic/editorial**
- **20% responsive motion**
- **7% GPU interaction**
- **3% signature spectacle**

The site should feel more advanced because it knows when **not** to animate.

## 2. Visual grammar

Every major effect should derive from a small semantic vocabulary.

### FRAME — cinema / viewpoint

Uses:

- hero aspect ratios;
- crop marks;
- scene boundaries;
- focus reticles;
- image masks;
- timecode framing;
- selection state.

### LENS — examination / deeper seeing

Uses:

- cursor;
- scene inspection;
- refraction;
- local relighting;
- image x-ray;
- magnification or semantic reveal.

### FRACTURE — moral rupture

Uses:

- dividers;
- severe timeline events;
- loading detail;
- transitions;
- Moral Core cracks;
- active state;
- evidence markers.

### TRACE — causality / consequence

Uses:

- causal graph lines;
- character arc trails;
- consequence chains;
- animated connectors;
- scroll progress in analytical sections.

### FOG — limited knowledge / uncertainty

Uses:

- Decision Chamber;
- unknown-to-character facts;
- interpretation confidence;
- obscured future consequences.

### CORE — moral structure

Uses:

- procedural film fingerprint;
- summary visualization;
- film comparison;
- transition anchor between page states.

### LIGHT — truth / disclosure

Use sparingly. Light should reveal, not merely decorate.

## 3. Color system

Base:

- near-black `#030303` / `#050505`;
- deep graphite / gunmetal for elevated layers;
- warm off-white / ivory for body text;
- cold gray for metadata;
- controlled crimson for moral rupture, guilt, danger or severe events;
- muted warm gold / amber only for restoration, grace, repentance, truth, or final editorial emphasis.

Rules:

- no purple/blue AI-SaaS gradients;
- no red glow on every element;
- no glass rainbow chromatic noise by default;
- dark does not mean low contrast: body copy must remain comfortably readable.

## 4. Typography

The visual hierarchy should combine one expressive editorial display face and one highly legible grotesk/sans face.

Principles:

- 1–2 primary families;
- extreme size contrast is allowed;
- display typography may be tightly tracked;
- long-form copy must use conservative line length and line-height;
- metadata uses a distinct micro-typographic system: timestamps, scene IDs, category labels;
- typography must remain selectable DOM text, not canvas text, except for rare decorative GPU treatments.

Reference principle: Obys uses typography, grids and motion as one system rather than independent decoration.

## 5. Motion grammar

Motion must follow narrative function.

### Quiet motion

- opacity;
- tiny depth shifts;
- 1–3 degree card perspective at most;
- subtle delayed secondary lines;
- shared-element movement.

### Analytical motion

- layers separate when a scene is examined;
- cause/effect traces draw progressively;
- fog reveals known vs unknown information;
- annotations attach to evidence;
- timeline fractures respond to severity.

### Signature motion

Reserve for a few moments:

- Film Dissection;
- Moral Core formation;
- Scene Autopsy;
- Decision Chamber reveal;
- final transition into Verdict.

Do not stack signature effects back-to-back.

## 6. Hero experience

The homepage should begin almost empty.

Suggested sequence:

1. BLACK / near-black field.
2. Minimal pointer / focus mark.
3. Manifesto statement.
4. A cinematic 2.39:1 frame emerges.
5. Pointer proximity activates depth and relighting.
6. Scroll begins to separate the frame into analytic layers.
7. A small set of concepts appears: ACT / MOTIVE / CONSEQUENCE.
8. The Moral Core starts forming from the analyzed material.
9. Site opens into the catalog / atlas.

Do not front-load menus, grids and cards before establishing identity.

## 7. Film page visual dramaturgy

The page should change visual language as analysis deepens.

| Stage | Visual language |
| --- | --- |
| Film Hero | cinematic / atmospheric |
| Synopsis | quiet editorial |
| Verdict Snapshot | restrained data |
| Moral Timeline | forensic |
| Scene Analysis | depth / x-ray |
| Difficult Decision | spatial |
| Moral Graph | abstract analytical |
| Scripture / Principle | warm editorial restraint |
| Final Verdict | stillness / luxury minimalism |

The final Verdict should be one of the calmest areas of the entire page.

## 8. Signature interaction: Moral Lens

Default cursor is a tiny light point with a subtle outer ring.

States:

- image: reticle / `EXAMINE`;
- film card: `OPEN`;
- timeline: timestamp;
- Decision Chamber: `WEIGH`;
- draggable 3D: `HOLD`;
- moral graph: soft magnetic attraction to nodes.

In GPU scenes, pointer position may control local light, refraction or field response.

Requirements:

- never break text selection;
- never hide the native cursor where precision is necessary;
- disable custom pointer treatment on touch;
- keyboard focus must have an equally clear visual state.

## 9. Signature interaction: Scene Autopsy

A normal cinematic image becomes an evidence field.

Sequence:

1. User chooses `ANALYZE SCENE`.
2. Subject / foreground / background separate using depth and masks.
3. Saturation and lighting become analytical rather than cinematic.
4. Key objects receive anchored annotations.
5. Timecode and scene ID appear.
6. ACT / MOTIVE / KNOWLEDGE / INTENT / PRESSURE / CONSEQUENCE appear contextually.
7. TRACE lines connect evidence to interpretation.
8. Optional Moral Lens exposes alternate layers.

The visual effect must explain the analysis, not simply make the image look 3D.

## 10. Signature interaction: Film Dissection

Transition from “watching the image” to “analyzing the image.”

Possible implementations:

- image ribbons / threads;
- segmented planes;
- depth layers;
- controlled datamosh as a rare rupture;
- mask separation;
- texture decomposition into semantic regions.

The conceptual meaning is: **the film is being opened into components**.

## 11. Signature object: Moral Core

Do not use a generic sphere or radar chart.

A film can generate a procedural sculptural fingerprint. Candidate parameter mapping:

- moral ambiguity → topology complexity;
- romanticization pressure → internal crimson emission;
- culpability density → mass / density;
- consequences → fracture depth;
- repentance → restoration / closing geometry;
- redemptive movement → internal warm light;
- narrative contradiction → asymmetry;
- uncertainty → surface instability / fog.

The mapping must be documented and deterministic enough that comparisons are meaningful.

The Editorial Core must remain separate from future Audience Field visualization.

## 12. Moral Timeline

The timeline is a major content surface, not a tiny player scrubber.

Candidate markers:

- ordinary moral event → dot;
- deliberate wrongdoing → cut;
- grave event → crimson fracture;
- difficult dilemma → split diamond;
- sacrifice → ivory flare;
- repentance → warm restoration;
- consequence → expanding trace/wave.

The timeline should reveal the moral rhythm of a film over time while preserving spoiler controls.

## 13. Decision Chamber

Full-screen or near-full-screen spatial analysis of a difficult choice.

Required semantic layers:

- option A / option B / optional C;
- character knowledge at decision time;
- facts unknown to character;
- coercion / pressure;
- duties / goods in conflict;
- foreseeable consequences;
- actual later consequences (spoiler-controlled);
- editorial conclusion and confidence.

### Knowledge Fog

Unknown information is literally obscured in Character Perspective mode. Switching to Omniscient Analysis removes the fog.

This is an example of a visual effect that teaches the analytical concept.

## 14. Catalog

Provide at least two modes eventually.

### INDEX MODE

Fast, typographic, searchable, data-forward, minimal motion.

### EXPLORE MODE

Large cinematic media, depth, controlled infinite/spatial browsing, shared transition into film detail.

The user should not be forced to navigate an immersive gallery when they simply want to find a title.

## 15. AI image production pipeline

AI imagery should be treated as source material for a web scene, not the finished asset.

Recommended per-film asset pipeline:

1. master cinematic artwork;
2. depth map;
3. segmentation masks;
4. foreground / subject / background extraction;
5. safe dark version for text;
6. macro symbolic detail;
7. abstract moral texture;
8. social variants where needed;
9. compressed AVIF/WebP delivery variants;
10. optional WebGPU material / relighting configuration.

Depth-map relighting is especially valuable because one high-quality 2D artwork can support parallax, local light, self-shadowing, fog, scene separation and transition behavior.

## 16. Glass usage

Glass is not a default component style.

Use only when it has optical meaning:

- Moral Lens;
- a major catalog lens;
- rare refraction surface;
- a physical analytical instrument.

If glass is used, prefer actual sampling/refraction/Fresnel logic over `backdrop-filter` as the entire effect.

## 17. Analog cinema texture

Use subtly:

- fine 35mm grain;
- restrained halation;
- projector / gate movement only in selected moments;
- contact sheet references;
- frame numbers;
- timecode;
- optical softness.

The site is contemporary, not retro. Analog details should preserve the feeling of cinema inside a 2026 interface.

## 18. Scripture / Principle mode

When the analysis moves from description to normative biblical principle, the visual language should intentionally calm down:

- less GPU movement;
- warmer ivory background accents;
- crimson recedes;
- narrower text column;
- strong editorial typography;
- careful citations;
- no “church parchment” aesthetic.

The shift should communicate: **we are moving from observation to norm**.

## 19. Forbidden clichés

- purple/blue neon gradients;
- glowing red everywhere;
- every card made of glass;
- permanent mouse trails;
- endless particles;
- generic wobbling blobs;
- exaggerated 3D card tilt;
- mandatory smooth-scroll lag;
- constant text scramble;
- excessive chromatic aberration;
- canvas-only text/UI;
- long unskippable intros;
- mandatory audio;
- “more animation = more premium.”

## 20. Accessibility is part of art direction

- respect `prefers-reduced-motion`;
- replace large transform/parallax with opacity or static composition in reduced-motion mode;
- offer non-drag controls for any required drag interaction;
- ensure pointer targets meet WCAG 2.2 minimum sizes;
- avoid flashing patterns;
- keep every meaningful claim accessible in DOM text;
- ensure keyboard navigation and visible focus;
- touch experience must be deliberately composed, not a disabled desktop version.

## 21. Performance tiers

Candidate runtime tiers:

### ULTRA
WebGPU, high-quality relighting, full Core, richer particles, premium post effects.

### HIGH
WebGPU/WebGL2, reduced effects, lower particle density.

### MEDIUM
WebGL2 / 2.5D, reduced DPR, simplified materials.

### LITE
DOM + images + Motion/CSS. No essential information may be lost.

Quality should adapt; meaning should not.
